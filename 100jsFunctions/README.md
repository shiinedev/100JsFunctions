## 📂 Project Structure

Each function is stored in a separate file under the `100jsFunctions` directory.  

Example:
```
100JsFunctions/
├── Beginner
├── Intermediate
├── Advanced

```

## 📦 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/shiinedev/100JsFunctions.git
   ```
2. Navigate to the `100jsFunctions` directory:
   ```bash
   cd 100JsFunctions/100jsFunctions
   ```
